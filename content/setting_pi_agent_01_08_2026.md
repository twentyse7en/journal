# Connecting to kimi
in a `pi` session, enter `/login`, that will show service providers and you can choose one.

# Shortcuts
`Shift + tab` : switch thinking level
`Ctrl + L`: model picker
`Ctrl + P`: switch model

*NOTE*: I want to use k3-256k model, it consume less token that k3 regular model (1M token), and k2.7 (kimi-for-coding), so run `/scoped-models` and enable only this, now I can switch faster with `Ctrl+P`.
